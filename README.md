# 🛒 AI-Enabled E-Commerce Platform

An AI-powered e-commerce platform designed to provide a smarter, more personalized, and efficient online shopping experience.

## 📂 Project Repositories

This project is organized into separate frontend and backend repositories.

### 🎨 Frontend Repository

The frontend repository contains the customer-facing e-commerce web application.

🔗 **GitHub:** [e-commerce-webSite](https://github.com/DonShanilka/e-commerce-webSite)

### ⚙️ Backend Repository

The backend repository contains the e-commerce microservices and server-side functionality.

🔗 **GitHub:** [E-Commerce_Microservices](https://github.com/DonShanilka/E-Commerce_Microservices)


## 📌 Overview

The **AI-Enabled E-Commerce Platform** is a full-stack e-commerce project that aims to integrate modern web technologies, microservices architecture, and Artificial Intelligence to improve the online shopping experience.

The platform is designed to support product discovery, personalized recommendations, intelligent search, and other AI-driven shopping features.

## ✨ Key Features

- 🛍️ Product browsing and management
- 🔍 Smart product search
- 🤖 AI-powered shopping assistant
- 🎯 Personalized product recommendations
- ⚖️ Product comparison
- ⭐ Customer reviews and sentiment analysis
- 🛒 Shopping cart and order management
- 🔐 Authentication and authorization
- 🧩 Microservices-based backend architecture
- 📱 Responsive user interface

*Note: Features are planned or under development unless already implemented in the codebase.*

## 🏗️ Architecture

The project follows a microservices-oriented architecture to support modular development, independent services, and future scalability.

## 🛠️ Technologies

The technology stack is being developed around modern full-stack technologies, including:

- **Frontend:** Next.js, React, TypeScript, Tailwind CSS
- **State Management:** Redux Toolkit
- **Backend:** Microservices architecture
- **AI/ML:** Intelligent search and recommendation capabilities
- **Database:** Based on individual service requirements
- **Version Control:** Git and GitHub


## 🚀 Getting Started

### Clone the Main Repository

```bash
git clone https://github.com/DonShanilka/AI-Enabled-E-Commerce-Platform.git
cd AI-Enabled-E-Commerce-Platform
```

### Clone the Frontend

```bash
git clone https://github.com/DonShanilka/e-commerce-webSite.git
```

### Clone the Backend

```bash
git clone https://github.com/DonShanilka/E-Commerce_Microservices.git
```

Follow the setup instructions in the respective frontend and backend repositories to install dependencies and run the applications.
